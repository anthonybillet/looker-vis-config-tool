How to Use This in LookML

  1. In Looker, open an Explore and configure your chart visualization how you want the drill-down to appear.
  2. Click the Gear icon (⚙️) in the top-right corner next to Run, click Share, and copy the Expanded URL.
  3. Paste the Expanded URL into the box above and click Copy vis_config.
  4. Implement it in your LookML project using either Option 1 (directly in a measure) or Option 2 (reusable manifest constant) below.

Option 1: Implement Directly in a Measure (view.lkml)

Option 2: Implement with a Reusable Constant (manifest.lkml + view.lkml)

To keep your view files clean and reuse the same drill visualization across multiple measures, store the {% assign vis_config %} block in a project constant inside manifest.lkml:

# 1. In manifest.lkml:
constant: scatter_plot_vis_config {
  value: "{% assign vis_config = '{
     \"stacking\" : \"\",
     \"show_value_labels\" : false,
     \"x_axis_gridlines\" : true,
     \"y_axis_gridlines\" : true,
     \"show_view_names\" : false,
     \"point_style\" : \"circle\",
     \"type\" : \"looker_scatter\",
     \"colors\": [
     \"palette: Santa Cruz\"
     ],
     \"trend_lines\": [
      {
      \"color\" : \"#000000\",
      \"label_position\" : \"left\",
      \"period\" : 30,
      \"regression_type\" : \"average\",
      \"series_index\" : 1,
      \"show_label\" : true,
      \"label_type\" : \"string\",
      \"label\" : \"30 day moving average\"
      }
     ]
    }' %}"
}

# 2. In your view.lkml file:
measure: count {
  type: count_distinct
  sql: ${id} ;;
  drill_fields: [created_date, total_sale_price]
  link: {
    label: "Show as scatter plot"
    url: "@{scatter_plot_vis_config}
          {{ link }}&vis_config={{ vis_config | encode_uri }}&toggle=dat,pik,vis&limit=5000"
  }
}
